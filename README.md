# English

Личный курс английского: уроки, словарь, речь. PWA для телефона, работает офлайн.

## Команды

```bash
npm install
npm run dev             # разработка на http://localhost:5173
npm run build           # типы + сборка в dist
npm run preview         # проверить production-сборку
npm run validate:content # проверка уроков и слов
npm run icons           # перегенерировать иконки из public/icon.svg
```

## Структура

```
src/
  content/        уроки, слова, типы, валидатор
  db/             IndexedDB: прогресс, дни, настройки, бэкап
  lib/            сессия дня, даты, речь, сравнение ответов
  components/     каркас интерфейса
  screens/        Сегодня, Путь, Урок, Словарь, Прогресс, Настройки
scripts/
  validate-content.ts
  make-icons.mjs
```

## Документы

- `SPEC.md` — что строим и как устроено.
- `CONTENT.md` — формат уроков и правила проверки.
- `DESIGN.md` — токены и правила дизайна.
- `CURRICULUM.md` — программа A1 → C1, американский английский.

## Деплой

Cloudflare Workers, статические ассеты из `dist`.

```bash
npm run build
npx wrangler deploy
```

Живой адрес: https://english-app.registerakm.workers.dev

Конфиг — `wrangler.jsonc`. SPA-роутинг включён через `not_found_handling: single-page-application`, отдельный `_redirects` не нужен.

## Ограничения

- Микрофон (`getUserMedia`) работает только на HTTPS или localhost. На телефоне проверять через задеплоенную версию, а не по локальной сети.
- Распознавание речи в Chrome требует интернета. Запись и сравнение — офлайн.
- TTS офлайн работает, если в системе скачан английский голосовой пакет.
