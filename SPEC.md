# SPEC — English

Личное приложение для изучения английского. Один пользователь, без сети для учёбы.

## Цель

A1/A2 → B2, IELTS 6.5–7.0 к лету 2028. Поступление в вуз США. Дальше — жизнь в стране.

## Среда

- Xiaomi 13 Ultra, Android 13, Chrome.
- PWA, установка на главный экран, работа офлайн.
- Данные: IndexedDB на устройстве. Экспорт/импорт JSON для бэкапа.
- Хостинг: Cloudflare Pages (статика).

## Принципы

1. Приложение отвечает на вопрос «что делать следующие 2 часа», а не «какие у меня есть уроки».
2. Урок короткий (10–15 мин), занятие длинное (2 ч). Долгий урок пугает, короткий — нет.
3. Офлайн — обычный режим, а не аварийный. Всё, что нужно для занятия, лежит на устройстве.
4. Один дизайн, сделанный хорошо. Никаких переключателей стилей.
5. Никаких механик удержания: сердца, энергия, таймеры, «премиум за жизни».
6. Прогресс не теряется: бэкап в один файл.

## Термины

| Термин | Значение |
|---|---|
| **Урок** (юнит) | Одна тема: карточка-формула + 5–8 упражнений. 10–15 мин. |
| **Блок** | Один из четырёх кусков занятия: курс, слушание, речь, повторение. |
| **Занятие** | Дневная сессия. Собирается автоматически под день недели и доступное время. |

## Экраны

Нижняя навигация, 4 вкладки. Настройки — иконка в шапке «Сегодня».

| Экран | Что делает |
|---|---|
| **Сегодня** | Собирает занятие на день: 4 блока с длительностью, кнопка «Начать». |
| **Путь** | Список юнитов по уровням: номер, тема, прогресс. Оглавление учебника. |
| **Урок** | Проигрыватель упражнений: формула → задания → результат. |
| **Словарь** | Слова из пройденных уроков, перевод, транскрипция, примеры, фото. |
| **Прогресс** | Процент курса, серия дней, слов в обороте, время за неделю. |
| **Настройки** | Время по дням, день с репетитором, бэкап, сброс. |

## Занятие

Длительность по умолчанию:

| Пн | Вт | Ср | Чт | Пт | Сб | Вс |
|---|---|---|---|---|---|---|
| 120 | 90 | 120 | 120 | 120 | 180 | 150 |

День с репетитором — переопределяется в настройках на 90 мин.

Состав от целевого времени: курс 50 %, слушание 25 %, речь 17 %, повторение 8 %.

Блок «курс» набирается из следующих незакрытых уроков: 3–4 урока по 12–15 мин.

Правила:
- начатый урок продолжается с того упражнения, где остановился;
- занятие не блокируется: нет слов к повторению — блок пропускается;
- время считается фактическое, а не целевое.

## Данные

**Контент** — TypeScript/JSON в бандле приложения. Офлайн из коробки, обновляется вместе с приложением. Формат — `CONTENT.md`.

**Прогресс** — IndexedDB, база `english`:
- `progress` — состояние по каждому уроку;
- `days` — журнал по дням (время, упражнения);
- `kv` — настройки и служебные ключи.

**Бэкап** — один JSON: настройки, прогресс, журнал, SRS. Экспорт через скачивание файла, импорт через выбор файла.

## Этапы

| Этап | Содержание | Статус |
|---|---|---|
| 0 | Спека, схема контента, токены, каркас, один настоящий урок | готово |
| 1 | Движок уроков, «Сегодня», «Путь», 10 уроков A1 | готово |
| 2 | Словарь + SRS + паки фото | дальше |
| 3 | Речь: запись, эталон, сравнение | — |
| 4 | Прогресс, серия, бэкап | — |
| 5 | Чтение A1, библиотека слушания | — |
| далее | Контент партиями по 10 уроков, до B2 | — |

Критерий готовности этапа 0:
1. приложение ставится на телефон и открывается без интернета;
2. урок A1 проходится целиком, все типы упражнений работают;
3. закрыл приложение — прогресс на месте;
4. дизайн проверен на реальном уроке;
5. `npm run validate:content` проходит.

## Границы

Не делаем: аккаунты, оплату, синхронизацию между устройствами, свою озвучку и аудиокурсы, соцфункции, механики удержания.

## Ограничения платформы

- Распознавание речи (Web Speech API) в Chrome отправляет звук на серверы Google и без интернета не работает. Запись и сравнение — офлайн; оценка произношения — бонус при наличии сети.
- TTS (`SpeechSynthesis`) работает офлайн, если в системе скачан английский голосовой пакет.
- Запись с микрофона (`getUserMedia`) требует HTTPS или localhost. На телефоне проверять через задеплоенную версию.
